# TypeScript Learning Project

This project is for learning TypeScript basics.

## Setup

```bash
npm install
```

## Run the project

```bash
npm run dev
```

This runs the file in `src/index.ts` using `ts-node`.

## Build the project

```bash
npm run build
```

## Run the compiled JavaScript

```bash
npm start
```

## Topics we will cover

- variables
- primitive types
- arrays and objects
- functions
- interfaces
- classes
- TypeScript with Node.js
